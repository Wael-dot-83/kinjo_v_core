# KinJo Homepage Replacement Copy

This copy set is intended to replace the claims and labels identified in the homepage audit. It deliberately avoids unsupported national percentages, endorsement language, and app-distribution promises. The Arabic copy is written as native user-facing copy rather than as a literal word-for-word translation.

## Voice rules

- Use “licensed kindergarten and early-childhood facility” in English; use “الحضانة أو منشأة الطفولة المبكرة المرخّصة” in Arabic where the full meaning is needed.
- Use “public registry” / “السجل العام” for searchable records.
- Use “license-eligible” / “مستوفية لشروط الترخيص” when describing the public filter.
- Reserve “accredited” / “معتمدة” for a status explicitly supplied by the official source.
- Prefer “families” or “parents and guardians” consistently; avoid switching between “parents,” “families,” and “caregivers” without a reason.
