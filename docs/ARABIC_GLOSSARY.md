# Arabic Glossary (Admin + Classification UI)

## Core terms
- Dashboard: لوحة التحكم
- KPI Dashboard: لوحة مؤشرات الأداء
- Classification: التصنيف
- Benchmarking: المقارنة المعيارية
- Ranking: الترتيب
- Percentile: النسبة المئوية
- Band: المجال
- Data Coverage: تغطية البيانات
- Insufficient Data: بيانات غير كافية

## Roles
- Admin: مدير النظام
- Manager: مدير الروضة
- Supervisor: مشرف
- Parent: ولي أمر

## Geography
- Network: الشبكة
- Country: الدولة
- Governorate: المحافظة
- City: المدينة
- Area: المنطقة
- Kindergarten: الروضة

## Trend and status
- Upward trend: صاعد
- Downward trend: هابط
- Stable: مستقر
- Green: أخضر
- Amber: كهرماني
- Red: أحمر
