      {% if ui_lang == 'en' %}How Is Your Final Score Calculated?{% else %}كيف يتم احتساب درجتك النهائية؟{% endif %}
      {% if ui_lang == 'en' %} Your Final Score is a number from 0 to 100 that reflects how consistently you recorded child attendance, submitted daily reports, and submitted them on time during the selected period. The higher the score, the better. {% else %} درجتك النهائية هي رقم من 0 إلى 100 يعكس مدى انتظامك في تسجيل حضور الأطفال، وإرسال التقارير اليومية، والالتزام بمواعيد إرسالها خلال الفترة المحددة. كلما ارتفعت الدرجة، كان أداؤك أفضل. {% endif %}
      {% if ui_lang == 'en' %}The Three Pillars of Your Score{% else %}ثلاثة محاور يُبنى عليها التقييم{% endif %}
      1 {% if ui_lang == 'en' %}Attendance Consistency{% else %}اتساق تسجيل الحضور{% endif %}
      40%

      {% if ui_lang == 'en' %} Measures how often you recorded attendance for your class on the expected working days. {% else %} يقيس عدد أيام تسجيل الحضور مقارنةً بأيام العمل المتوقعة للصفوف المسندة إليك. {% endif %}

      {% if ui_lang == 'en' %} (Days Recorded ÷ Expected Days) × 100 {% else %} (أيام التسجيل ÷ الأيام المتوقعة) × 100 {% endif %}

      {% if ui_lang == 'en' %} Example: 18 days recorded out of 20 expected → 90% {% else %} مثال: سجّلت 18 يوماً من أصل 20 يوم عمل → 90% {% endif %}

      2 {% if ui_lang == 'en' %}Report Completion{% else %}اكتمال التقارير{% endif %}
      40%

      {% if ui_lang == 'en' %} Measures how many daily reports you submitted compared to the number of working days expected. {% else %} يقيس عدد التقارير اليومية التي أرسلتها مقارنةً بأيام العمل المتوقعة. {% endif %}

      {% if ui_lang == 'en' %} (Reports Submitted ÷ Expected Days) × 100 {% else %} (التقارير المرسلة ÷ الأيام المتوقعة) × 100 {% endif %}

      {% if ui_lang == 'en' %} Example: 17 reports out of 20 expected → 85% {% else %} مثال: أرسلت 17 تقريراً من أصل 20 → 85% {% endif %}

      3 {% if ui_lang == 'en' %}Report Timeliness{% else %}الالتزام بالوقت{% endif %}
      20%

      {% if ui_lang == 'en' %} Measures the percentage of your submitted reports that were sent on time (before the daily deadline). {% else %} يقيس نسبة التقارير التي أرسلتها قبل انتهاء الموعد اليومي المحدد. {% endif %}

      {% if ui_lang == 'en' %} (On-Time Reports ÷ Total Submitted) × 100 {% else %} (التقارير في الوقت ÷ إجمالي المرسل) × 100 {% endif %}

      {% if ui_lang == 'en' %} Example: 14 on-time out of 17 submitted → 82% {% else %} مثال: 14 تقريراً بالوقت من أصل 17 مرسل → 82% {% endif %}

      {% if ui_lang == 'en' %}The Formula{% else %}المعادلة{% endif %}
      {% if ui_lang == 'en' %}
      Final Score =
      (Attendance % × 40%) + (Report Completion % × 40%) + (Timeliness % × 20%)
      ÷ total active weights
      {% else %}
      الدرجة النهائية =
      (نسبة الحضور × 40%) + (نسبة التقارير × 40%) + (نسبة الالتزام × 20%)
      مقسومةً على مجموع الأوزان الفعلية
      {% endif %}
      {% if ui_lang == 'en' %}Worked Example{% else %}مثال تطبيقي{% endif %}
      {% if ui_lang == 'en' %}Attendance{% else %}الحضور{% endif %}
      18 ÷ 20 × 100 = 90%
      × 40% = 36 pts
      {% if ui_lang == 'en' %}Reports{% else %}التقارير{% endif %}
      17 ÷ 20 × 100 = 85%
      × 40% = 34 pts
      {% if ui_lang == 'en' %}Timeliness{% else %}الالتزام{% endif %}
      14 ÷ 17 × 100 = 82%
      × 20% = 16.4 pts
      {% if ui_lang == 'en' %} Final Score = (36 + 34 + 16.4) ÷ 100 = 86.4 / 100 🟢 Excellent {% else %} الدرجة النهائية = (36 + 34 + 16.4) ÷ 100 = 86.4 / 100 🟢 ممتاز {% endif %}
