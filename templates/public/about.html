{% if ui_lang == 'en' %}What is KinJo?{% else %}ما هو كينجو؟{% endif %}

{% if ui_lang == 'en' %} KinJo is a kindergarten enrollment and management platform built for Jordan. It connects parents, kindergarten managers and supervisors, and education administrators on a single system to manage child enrollment, daily attendance, daily activity reports, incident reporting, and communication between families and kindergartens. {% else %} كينجو منصة لتسجيل وإدارة الحضانات في الأردن. تجمع المنصة أولياء الأمور ومديري ومشرفي الحضانات والمسؤولين التربويين في نظام واحد لإدارة تسجيل الأطفال، والحضور اليومي، والتقارير اليومية للأنشطة، والإبلاغ عن الحوادث، والتواصل بين الأسر والحضانات. {% endif %}

{% if ui_lang == 'en' %}Who uses KinJo?{% else %}من يستخدم كينجو؟{% endif %}

  • {% if ui_lang == 'en' %}Parents — enroll children, track attendance, and review daily reports.{% else %}أولياء الأمور — لتسجيل الأطفال، ومتابعة الحضور، ومراجعة التقارير اليومية.{% endif %}
  • {% if ui_lang == 'en' %}Kindergarten managers and supervisors — manage classes, staff, and daily operations.{% else %}مديرو ومشرفو الحضانات — لإدارة الشعب والكوادر والعمليات اليومية.{% endif %}
  • {% if ui_lang == 'en' %}Administrators — oversee enrollment, safety, and performance across kindergartens.{% else %}المسؤولون — للإشراف على التسجيل والسلامة والأداء عبر الحضانات.{% endif %}
