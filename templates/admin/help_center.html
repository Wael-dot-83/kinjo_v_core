{% if ui_lang == 'en' %}About the Admin module{% else %}نبذة عن وحدة الإدارة{% endif %}

{% if ui_lang == 'en' %}The Admin module brings together platform monitoring, users, kindergartens, communication, daily reports, safety, analytics, governance, and audit tools. Access is enforced by the server; hiding a control is never an authorization boundary.{% else %}تجمع وحدة الإدارة أدوات مراقبة المنصة والمستخدمين والحضانات والتواصل والتقارير اليومية والسلامة والتحليلات والحوكمة والتدقيق. يفرض الخادم صلاحيات الوصول؛ وإخفاء عنصر في الواجهة ليس وسيلة تفويض.{% endif %}

{% if ui_lang == 'en' %}Use the reference ID shown with an error when escalating a problem so support can correlate the browser request with server logs.{% else %}استخدم الرقم المرجعي الظاهر مع الخطأ عند تصعيد المشكلة لربط طلب المتصفح بسجلات الخادم.{% endif %}

{% if ui_lang == 'en' %}Dashboard metrics{% else %}مؤشرات لوحة التحكم{% endif %}

{% if ui_lang == 'en' %}The dashboard contains seven operational indicators with different stated windows: current totals, today, the selected report period, or the fixed seven-day coverage window. They are measured results, not fixed targets.{% else %}تعرض لوحة التحكم سبعة مؤشرات تشغيلية بنوافذ زمنية موضحة ومختلفة: الإجماليات الحالية أو اليوم أو فترة التقارير المحددة أو نافذة التغطية الثابتة لسبعة أيام. وهي نتائج مقاسة وليست أهدافًا ثابتة.{% endif %}

{% if ui_lang == 'en' %}Users{% else %}إدارة المستخدمين{% endif %}

  1. {% if ui_lang == 'en' %}Open Users and filter by role, status, or kindergarten.{% else %}افتح المستخدمين وصفِّ النتائج حسب الدور أو الحالة أو الحضانة.{% endif %}
  2. {% if ui_lang == 'en' %}Create or edit an account within your permitted scope. A role sets the general access level; the server applies detailed restrictions.{% else %}أنشئ حسابًا أو عدله ضمن نطاق صلاحيتك. يحدد الدور مستوى الوصول العام ويطبق الخادم القيود التفصيلية.{% endif %}
  3. {% if ui_lang == 'en' %}For an Admin reset, enter the new password and your own current administrator password. This is not an emailed reset-link workflow.{% else %}لإعادة التعيين الإداري أدخل كلمة المرور الجديدة وكلمة مرورك الحالية كمسؤول. هذه ليست عملية إرسال رابط بالبريد الإلكتروني.{% endif %}

{% if ui_lang == 'en' %}Kindergartens{% else %}إدارة الحضانات{% endif %}

{% if ui_lang == 'en' %}Use Kindergarten Overview for network monitoring and Kindergarten Records for create, view, edit, freeze, activate, manager-assignment, licence, location, and capacity information. Required create fields include the Arabic name, governorate, district, area, address line, and contact phone.{% else %}استخدم نظرة الحضانات لمراقبة الشبكة وسجل الحضانات للإنشاء والعرض والتعديل والتجميد والتفعيل وتعيين المدير وبيانات الترخيص والموقع والطاقة الاستيعابية. تشمل حقول الإنشاء المطلوبة الاسم العربي والمحافظة واللواء والمنطقة والعنوان ورقم الاتصال.{% endif %}

{% if ui_lang == 'en' %}Open Kindergarten Overview{% else %}فتح نظرة الحضانات{% endif %}

{% if ui_lang == 'en' %}Data imports{% else %}استيراد البيانات{% endif %}

{% if ui_lang == 'en' %}Download the provided template, validate the file, and review created, updated, skipped, and error rows returned for that import type. Imported Kindergarten Data is a review list, while Import History records each job and its row/error counts.{% else %}نزّل النموذج المتاح وتحقق من الملف ثم راجع الصفوف المنشأة والمحدثة والمتجاوزة والخاطئة التي يعيدها نوع الاستيراد. صفحة بيانات الحضانات المستوردة قائمة للمراجعة، بينما يسجل سجل الاستيراد كل عملية وأعداد الصفوف والأخطاء.{% endif %}

{% if ui_lang == 'en' %}Communication{% else %}التواصل{% endif %}

{% if ui_lang == 'en' %}Compose Message lets you choose a target mode, location or kindergarten, and applicable roles. Preview is an estimate; the server recalculates recipients when sending. The Message List currently shows the latest 25 messages. Contact Messages can be reviewed and marked resolved, but it is not a ticket-reply system.{% else %}تتيح صفحة إنشاء رسالة تحديد طريقة الاستهداف والموقع أو الحضانة والأدوار المناسبة. المعاينة تقديرية ويعيد الخادم حساب المستلمين عند الإرسال. تعرض قائمة الرسائل أحدث 25 رسالة حاليًا. يمكن مراجعة رسائل التواصل ووضع علامة تمت المعالجة، لكنها ليست نظام تذاكر وردود.{% endif %}

{% if ui_lang == 'en' %}Compose a message{% else %}إنشاء رسالة{% endif %}

{% if ui_lang == 'en' %}Daily reports{% else %}التقارير اليومية{% endif %}

{% if ui_lang == 'en' %}Daily Reports Analytics covers attendance, meals, naps, health indicators, and report workflow by period and kindergarten. Daily Report Organization searches, groups, sorts, and reviews reports; it does not create report schedules. Governance measures submission, delivery, viewing, acceptance, and timing according to each displayed definition.{% else %}تشمل تحليلات التقارير اليومية الحضور والوجبات والقيلولة والمؤشرات الصحية ومسار التقرير حسب الفترة والحضانة. تبحث صفحة تنظيم التقارير اليومية في التقارير وتجمعها وتفرزها وتراجعها؛ ولا تنشئ جداول إرسال. تقيس الحوكمة التقديم والتسليم والمشاهدة والقبول والتوقيت وفق تعريف كل مؤشر ظاهر.{% endif %}

{% if ui_lang == 'en' %}Open Daily Reports Analytics{% else %}فتح تحليلات التقارير اليومية{% endif %}

{% if ui_lang == 'en' %}Incidents and safety{% else %}الحوادث والسلامة{% endif %}

{% if ui_lang == 'en' %}Generated Incident Reports are analytical snapshots, not the live incident queue. Incident Analytics shows open/closed totals, severity, type, parent-notification state, and repeated-child patterns. Treat child-level information as confidential and export only for an approved purpose.{% else %}تقارير الحوادث المنشأة لقطات تحليلية وليست قائمة الحوادث الحية. تعرض تحليلات الحوادث الإجمالي والمفتوح والمغلق والخطورة والنوع وحالة إبلاغ ولي الأمر وأنماط تكرار الحالات لدى الأطفال. تعامل مع معلومات الطفل بسرية ولا تصدرها إلا لغرض معتمد.{% endif %}

{% if ui_lang == 'en' %}Analytics and reports{% else %}التحليلات والتقارير{% endif %}

{% if ui_lang == 'en' %}Before interpreting a rate, confirm its numerator, denominator, period, entity scope, unit, data coverage, and last update. Predictions, benchmarks, anomaly detection, and what-if results are analytical outputs rather than observed facts. Export only formats offered by the selected report; availability differs by report.{% else %}قبل تفسير أي نسبة تحقق من البسط والمقام والفترة ونطاق الجهة والوحدة وتغطية البيانات ووقت آخر تحديث. التنبؤات والمقارنات وكشف القيم غير الاعتيادية ونتائج السيناريوهات مخرجات تحليلية وليست حقائق مرصودة. صدّر فقط الصيغ التي يتيحها التقرير المحدد؛ إذ تختلف الصيغ حسب التقرير.{% endif %}

{% if ui_lang == 'en' %}Governance and classification{% else %}الحوكمة والتصنيف{% endif %}

{% if ui_lang == 'en' %}Daily Report Governance explains reporting rates and reminder eligibility. Compliance Reminders is a sending-history page; the send action is available from Governance Reports. Classification and Benchmarks must show score composition and coverage, and entities with insufficient coverage must not receive a misleading rank.{% else %}تشرح حوكمة التقارير اليومية نسب التقارير وأهلية إرسال التذكير. صفحة تذكيرات الالتزام سجل للإرسال؛ ويتوفر إجراء الإرسال من تقارير الحوكمة. يجب أن يوضح التصنيف والمقارنات مكونات الدرجة والتغطية، وألا تحصل الجهات ذات التغطية غير الكافية على ترتيب مضلل.{% endif %}

{% if ui_lang == 'en' %}Security and audit{% else %}الأمان والتدقيق{% endif %}

{% if ui_lang == 'en' %}Unsafe requests require a matching CSRF cookie and header. Audit export is available from the Audit Log page and respects the selected filters and period. Retention and authorized cleanup are operational controls, so do not describe logs as impossible to remove. Controlled User Access is only for an approved support case and records start/end activity and reason.{% else %}تتطلب الطلبات المعدلة للبيانات تطابق ملف تعريف ارتباط CSRF مع الترويسة. يتوفر تصدير التدقيق من صفحة سجل التدقيق ويحترم المرشحات والفترة المحددة. الاحتفاظ والتنظيف المصرح به ضوابط تشغيلية، لذلك لا توصف السجلات بأنها غير قابلة للإزالة. يستخدم الدخول المقيّد بصفة مستخدم لحالة دعم معتمدة فقط ويسجل البدء والانتهاء والسبب.{% endif %}

{% if ui_lang == 'en' %}Open Audit Log{% else %}فتح سجل التدقيق{% endif %}
